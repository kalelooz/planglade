# Support and reporting

PlanGlade is maintained on a best-effort basis without a response-time SLA.

## Bugs

Use the [bug report form](https://github.com/kalelooz/planglade/issues/new?template=bug_report.yml).
Search existing issues first and remove private workspace data, credentials,
tokens, database URLs, and secret-bearing links from logs or screenshots.

## Feature requests and questions

Use the [feature request form](https://github.com/kalelooz/planglade/issues/new?template=feature_request.yml).
For a usage question, a normal issue is acceptable while GitHub Discussions is
not enabled. Include the PlanGlade version or commit and deployment method.

## Security

Do not use a normal issue. Follow [SECURITY.md](../SECURITY.md) and use GitHub
Private Vulnerability Reporting. If that control is unavailable, use the
security contact request link in the issue chooser without including any
vulnerability details; a maintainer can establish a private follow-up channel.

## Conduct concerns

Use the conduct contact request in the issue chooser and provide only a request
for private follow-up. Do not identify affected people or describe the incident
in the public issue.
